# Zapret Discord

YouTube Unban · Discord connecting / RTC · обход DPI без VPN

**[CircuitTonePlain/zapret-discord](https://github.com/CircuitTonePlain/zapret-discord)** — сборка для Windows 10/11

[**⬇ Скачать последний релиз**](https://github.com/CircuitTonePlain/zapret-discord/releases/latest)

Обход замедлений **YouTube**, **Discord** (голос / RTC) и **Telegram** без VPN.

> [!IMPORTANT]
> Запускайте `.bat` только после распаковки архива. Путь без кириллицы. Одновременно с VPN обычно не работает.

## Быстрый старт

1. Откройте [**Releases → Latest**](https://github.com/CircuitTonePlain/zapret-discord/releases/latest) и скачайте **`zapret-discord-youtube.rar`** (предпочтительно) или **`zapret-discord-youtube.zip`**
2. ПКМ по архиву → **Свойства** → **Разблокировать** (если есть)
3. Распакуйте по пути без кириллицы / спецсимволов
4. Запустите нужный `.bat` **от имени администратора**

## Файлы в корне

- **`Запуск всех сервисов.bat`** — Discord + YouTube + Telegram
- **`Обход Discord.bat`** — голос, медиа, Discord connecting / RTC
- **`Обход YouTube.bat`** — буферизация, 4K, Shorts
- **`Обход Telegram.bat`** — Telegram без прокси
- **`Статус подключения.bat`** — проверка / диагностика

Работоспособность зависит от провайдера. Если один вариант не помог — попробуйте другой bat из корня.
